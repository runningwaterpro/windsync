# windsync

清风输入法（WindInput）用户数据的多机同步工具。

把**用户词库、临时词、词频、候选调整、短语、配置**在多台电脑之间保持一致，并且能回到过去任意一次同步的状态。

> 状态：整理中，尚未发布。下面的内容会随代码一起完善。

## 它解决什么问题

清风输入法没有云同步，也没有账号体系。换一台电脑，词库就断了；想退回昨天，也没有入口。

这个工具用 Git 当传输和版本记录，把清风自己的导出/导入能力串成一个动作：

```
点一次「同步」= 取远端 → 合并 → 存快照 → 推上去
```

## 主要特性

- **一个按钮**：取、并、存、推合成一个动作，不存在「没取就存」的顺序错误
- **多机不限台数**：机器名只是标签，加第三台、第四台不用改代码
- **可回到过去**：每次同步是一个提交，可以整体回滚
- **删词可控**：「发布本机」整体覆盖远端，避免删掉的词被并集补回来
- **自动备份**：同步前用清风自己的 `backup create` 存一份整机档案
- **只用 Python 标准库**：不需要额外依赖，双击即用

## 环境要求

- Windows
- 清风输入法（每个方案至少一条词）
- Python 3.8+
- Git for Windows

## 计划中的使用方式

1. 在 Gitee 或 GitHub 建一个空仓库（私有也可以）
2. 拿到本工具
3. 填机器名、清风安装目录、仓库地址
4. 第一台机器点「同步」，其余机器点「恢复」

## 关于数据

本仓库只放程序代码，**不含任何用户词库或输入记录**。

同步的数据存在使用者自己创建的仓库里，与这个仓库无关。
